# AXON v1.1 Engineering Roadmap (ROADMAP_v1.1.md)

## 1. Planned v1.1 Ecosystem Enhancements

- **AXON WASM Native Verifier**: Compile AP-VM evaluator to WebAssembly (`axon_verifier.wasm`) for 0-server browser verification.
- **Streaming Large Object Verifier**: Partial chunked verification for payloads $> 100$ MB.
- **Go & Rust Core Engines**: Dedicated native Go and Rust verification libraries.
- **Enhanced AP-L String Operations**: Support regex pattern matching (`matches(regex)`).
